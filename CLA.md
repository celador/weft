## How to sign

Put this sentence in the description of each pull request you open, with your GitHub username:

> I have read the Weft CLA (CLA.md, version 1.0) and agree to it for this contribution. — @username

If you contribute as part of your job, add: "I contribute on behalf of <employer>, which has
authorized me to agree to the CLA for it." The pull request template already has the sentence.
Pull requests without it are not merged.
