Connect a machine

Run this once on each machine. It shows a code to confirm here, then your repos there use your hosted space.

In a terminal
npx @celador/weft login

Then in a repo: npx @celador/weft --hosted. Local Weft (npx @celador/weft) needs no account and sends nothing.

To add a teammate on another machine, run npx @celador/weft invite in this repo and send them the command it prints. It works once, for 30 minutes, and gives them their own key. See or remove teammates with npx @celador/weft members.
