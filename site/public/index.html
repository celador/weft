Merge time is too late.

Git coordinates people when they open a pull request. Agents in parallel worktrees break each other's assumptions every few minutes. By the time the PR shows a conflict, an agent has spent an hour building on a function signature that no longer exists.

One ordered log per repo. The verdict goes back to the agent.

  1. Hook

    An adapter catches each Edit, Write or apply_patch call before it touches disk, and records the symbols it reads and writes.

  2. Sequence

    One Durable Object per repo orders every edit and checks it against everything that landed since the agent's base, down to the symbol.

  3. Answer

    Allow, advise or deny. A denied agent gets a compiler-style diagnostic in its tool result, and exactly one side is told to adapt.

The agent reads the diagnostic. You don't have to.

An open protocol, not a walled garden.

Every agent runtime has hooks, and none of them are interoperable. Weft runs on two small specs anyone can implement: Agent Hooks Core for the hook semantics, and WCP for coordination on top.

WCP v0.1 is a draft and Weft is a research prototype. The analyzer understands TypeScript today.

  • Agent Hooks Core v0.1Capability levels L0 to L3, lifecycle events, the allow/advise/deny envelope.
  • Weft Coordination ProtocolThe ordered log, symbol claims, diagnostics and landings.
  • Conformance suiteRun any hook command through the fixtures and see which level it verifies.
  • Integration guideWire Weft into the agent setup you already run.
