The short version

  • Free: personal projects, learning, open-source work you aren't paid for, and 30 days of evaluation at work.
  • Needs a license: using Weft on code for your employer, for a client, or for a product or service that earns money.
  • Price: $29 per user per year, or $58 per user once (it never renews). Weft Pro includes the commercial license for every Pro user.
  • Builds you make yourself from the source code are covered by the AGPL-3.0 only, not by these terms.
  • Weft never blocks you or reports what you do with it. We trust you to buy a license when you need one.

What these terms cover

The builds of Weft that we distribute:

  • the @celador/weft npm package (npx @celador/weft: the CLI, the local gateway, the agent adapters and the MCP server),

  • the hosted service (hosted spaces on Weft's gateway).

They do not cover:

  • Builds from source. If you build Weft yourself from github.com/celador/weft, your build is governed by the GNU AGPL-3.0 only, and you don't need a commercial license for it.

What counts as commercial use

Commercial use means using Weft for work that you are paid for or that makes money. For a coding tool, that is mostly about whose code your agents are working on.

Commercial (needs a license):

  • Running Weft on your employer's code, or on code you write as part of your job.
  • Running Weft on a client's code: freelance, contract, consulting or agency work.
  • Running Weft on code for a product or service that earns revenue or is meant to (a startup, a SaaS, a paid app, an app with ads), including your own.
  • Using Weft inside a company, for internal tools too.

Not commercial (free):

  • Personal projects that don't earn money.
  • Learning: tutorials, courses, school work, trying out agents.
  • Maintaining open-source projects when you aren't paid to maintain them.
  • Evaluating Weft at work for up to 30 days before you decide.

Not sure? If someone pays you for the code your agents are writing, it's commercial. Email john@elier.ai for anything in between; we would rather make it work than turn you away.

Who counts as a user

A user is a person who uses Weft or whose coding agents Weft coordinates. Agents are not users: one developer running five agents needs one license. A team of four developers needs four.
