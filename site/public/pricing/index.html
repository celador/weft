Questions

What counts as a user?

One person whose coding agents work in the space. Agents don't count: one person running five agents is one user. Weft has no accounts, so you pick the number, and you can change it any time with npx @celador/weft billing.

Can teammates on other machines join my space?

Yes. Run npx @celador/weft invite in your repo. It prints a one-time code and the command your teammate runs in their clone. They get their own key, never yours, and their agents' edits are checked against yours. npx @celador/weft members shows who joined and removes anyone at once. Pro is per user: add a seat for each person with npx @celador/weft billing.

What happens when a free hosted space passes 5,000 events?

Your agents keep working, but their edits aren't coordinated until the next month (UTC), and each agent is told so. Reads and the feed keep working. Upgrade to Pro, or switch to your own gateway with npx @celador/weft use local, which has no limit. An event is one edit, claim, release or checkpoint an agent adds to the log. Heartbeats, reads, checks that pass and everything a human does are free.

Where does my code go?

On Free it stays on your machine; self-hosted and Pilot send edit events to a Worker in your Cloudflare account. On Pro, edit events (file paths, diffs, symbol names) go to Weft's gateway on Cloudflare and stay there until you erase the space with npx @celador/weft uninstall --space. Stripe holds your email and card; Weft keeps the Stripe customer id, the plan and the number of users. Privacy policy.

Does Weft stop agents from conflicting?

It catches conflicts while the agents are still editing: an agent whose edit relies on code another agent just changed gets a diagnostic in its tool result and fixes its own edit. You choose whether such an edit is blocked or only flagged (enforce or advise mode).

Can I cancel?

Yes, any time. npx @celador/weft billing opens Stripe's billing page, where you change the number of users, update your card or cancel. When Pro ends, the space goes back to Free. Nothing is deleted.

Who bills me?

Stripe, as "Atelier", in US dollars, at the start of each month or year.

Is it open source?

Yes, MIT, at github.com/celador/weft. Pro pays for the hosted service. The code is the same.

What if Weft goes down?

Agents keep working. After 5 seconds the adapter lets the edit through and tells the agent it was not coordinated.
