Something broken, or a question

  • GitHub issues: github.com/celador/weft/issues. Include the output of npx @celador/weft status with the feed line removed (that link is your space's read key), and which agent harness you use.
  • Email: john@elier.ai, for anything you'd rather not post publicly, including deleting a hosted space or security reports.

Quick checks

  • /weft:status in Claude Code, or npx @celador/weft status in the repo, shows the gateway, the space, the checkouts and recent events.
  • Agents that were already running when you set Weft up need a restart to load its hooks (the Claude Code plugin works without one).
  • Remove Weft from a repo with npx @celador/weft uninstall (--space also deletes the hosted space).
